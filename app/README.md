# NoC Organizer

Back office of the **Night of Chances** organizers, built on the NoC platform library
`@donorlin/noc-ui` – in [`packages/noc-ui`](packages/noc-ui/README.md) of this repository.

> **Workshop?** Start at the [repository README](../README.md).

Branches: `main` – the start state, the `programme` feature is only specified in
[`../specification/programme/`](../specification/programme/README.md) · `step-1-api` · `step-2-list` · `solution` (with the detail
screen and tests).

## Quick start

Requires Node.js 22.12+.

```bash
npm install
npm run dev          # http://localhost:5173, /api is served by MSW mocks
```

## Scripts

| Script                    | What it does                                                              |
|---------------------------|---------------------------------------------------------------------------|
| `npm run dev`             | Vite dev server with MSW mocks                                            |
| `npm run build`           | Type check and production build to `dist/`                                |
| `npm run check:ui`        | Types, lint, tests and docs check of `packages/noc-ui`                    |
| `npm run dev:ui`          | Playground of all noc-ui components at http://localhost:5180              |
| `npm run check:types`     | TypeScript                                                                |
| `npm run lint`            | ESLint                                                                    |
| `npm test`                | Vitest + Testing Library, network mocked by the same MSW handlers         |
| `npm run validate:schema` | Lint the OpenAPI contracts listed in `redocly.yaml`                       |
| `npm run generate:api`    | Generate TanStack Query hooks and types from the contracts (orval)        |

## Stack

React 19 · TypeScript · Vite · React Router · TanStack Query · `@donorlin/noc-ui` (Radix UI, TanStack Table,
react-hook-form + zod) · orval · MSW · Vitest.

## Project layout

```text
src/
├── main.tsx              # bootstrap, starts MSW in development
├── app/                  # providers, router, root layout, error and 404 pages
├── features/             # one folder per feature, registered in features/index.ts
│   └── home/
├── api/                  # http-client.ts + one folder per backend API (generated by orval)
├── mocks/                # MSW handlers and synthetic data, per API
└── test/                 # test setup and render helpers
packages/noc-ui/          # the UI platform library (npm workspace, used as source) with docs/
docs/                     # development, conventions, API and mocks, testing
.agents/skills/           # agent skills of the platform (.claude/skills links here)
```

See [ARCHITECTURE.md](ARCHITECTURE.md) for how it fits together.
